
# 群友弹鼻屎

一个适用于 AstrBot 的群聊娱乐插件，支持弹鼻屎互动、随机事件、群友数据记录和整点随机播报。

## 功能介绍

- **弹鼻屎互动**：在群聊中与群友进行趣味互动。
- **群友数据记录**：记录群友的相关游戏数据。
- **随机事件**：触发趣味事件并获得相应的经验或数据变化。
- **整点随机弹射**：每到整点随机抽取一名群成员进行群内播报。
- **每日鼻屎王播报**：支持每日播报相关排行结果。
- **免打扰时段**：可以设置自动播报的免打扰时间，避免深夜频繁发送消息。
- **独立群配置**：支持按群管理相关功能设置。

## 安装方法

1. 下载本仓库的 ZIP 文件，或将仓库克隆到本地。
2. 将插件文件夹 `astrbot_plugin_booger` 放入 AstrBot 的插件目录。
3. 在 AstrBot 管理面板中重载插件，或根据实际部署方式重启 AstrBot。
4. 在插件管理页面中检查插件是否正常加载。
5. 根据需要调整插件配置。

## 配置说明

插件支持通过 AstrBot 插件配置页面调整相关选项。具体配置项以插件实际提供的配置页面为准。

### 免打扰时段

免打扰功能用于限制自动播报的发送时间，避免在夜间打扰群聊。

默认设置：

- 启用免打扰：开启
- 开始时间：`00:00`
- 结束时间：`08:00`

时间采用 24 小时制。

例如，开始时间设置为 `00:00`、结束时间设置为 `08:00`，表示每天午夜至早上 8 点处于免打扰时段。

免打扰期间，受该设置控制的自动播报将暂停发送。手动触发的互动功能不受自动播报时段限制，具体行为以插件实现为准。

## 使用说明

插件安装并成功加载后，可在群聊中使用插件提供的互动功能。

不同功能的触发方式、指令和可配置选项，请以插件代码及 AstrBot 插件配置页面中的实际内容为准。

## 注意事项

- 请确保 AstrBot 已正常连接对应的聊天平台。
- 自动播报需要机器人具备向目标群发送消息的权限。
- 随机抽取群成员等功能依赖聊天平台适配器提供的相关接口。
- 如果自动播报没有正常发送，请检查插件运行日志、群配置以及机器人权限。
- 更新插件前，建议备份原有数据目录，避免误删游戏数据。
