# 群友弹鼻屎

一款用于 AstrBot 群聊的互动小游戏，支持群友弹射、互助清理、排行榜、成就称号、料理玩法和定时播报。

## 功能介绍

- **弹射互动**：指定群友或随机选择目标，触发命中、闪避、反弹等结果。
- **互助清理**：清理自己或帮助其他群友清理。
- **个人状态**：查看鼻屎数量、恶臭值、游戏统计和称号。
- **排行榜**：查看鼻屎数量、恶臭值、弹射统计及每日、每周榜单。
- **成就系统**：达成指定条件后解锁对应称号。
- **料理玩法**：制作随机料理、查看群内菜单，并随机享用料理。
- **自动播报**：支持整点随机弹射、每日天选之子和每日鼻屎王播报。
- **图片展示**：提供图片版玩法菜单和成就图鉴。

## 安装

1. 下载插件 ZIP 安装包。
2. 在 AstrBot 管理面板的插件页面安装并启用。
3. 在群聊中发送 `/弹鼻屎游戏` 查看玩法菜单。

## 配置

插件配置页面提供整点播报总开关及免打扰时段设置。群主也可以使用 `/整点播报 开` 或 `/整点播报 关` 单独控制当前群的整点播报。

## 数据存储

游戏数据保存在：

```text
data/plugin_data/astrbot_plugin_booger/booger_state.json
```

更新插件时会读取已有数据。手动替换或迁移插件目录前，建议保留该数据文件。

## 兼容性

群成员名单、昵称获取及自动播报能力取决于当前 AstrBot 版本和消息平台适配器提供的接口。
