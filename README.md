# 群友弹鼻屎

一个用于 AstrBot 群聊的轻松整活小游戏。群友可以互相“弹鼻屎”、帮忙擦鼻屎、查看个人状态和排行榜，并争夺每日的「鼻屎王」。所有数值均为虚构的游戏数据。

## 功能特色

- **图片版玩法菜单**：发送指令查看游戏玩法。
- **指定目标弹射**：通过 @ 群友指定弹射目标。
- **随机弹射**：随机抽取可用群友作为目标。
- **个人状态**：查看自己的鼻屎数量与恶臭值。
- **互相帮擦**：尝试帮其他群友清理，可能成功，也可能发生转移事故。
- **排行榜**：查看鼻屎数量、恶臭值及弹射命中统计。
- **每日鼻屎王**：统计当天被命中的次数，并尝试在每天 23:00 播报。
- **每小时整点播报**：可在插件配置中全局开启或关闭，也可通过群聊指令单独控制。
- **免打扰时段**：支持配置免打扰时间，默认 00:00–08:00。
- **本地持久化**：游戏数据保存在 AstrBot 的插件数据目录中，重启后可以继续使用。

## 指令列表

以下指令均在群聊中使用。若机器人或平台适配器不支持对应的消息功能，部分操作可能无法正常执行。

| 指令 | 用法 | 参数 | 功能说明 |
| --- | --- | --- | --- |
| `/弹鼻屎游戏` | `/弹鼻屎游戏` | 无 | 显示图片版玩法菜单。 |
| `/弹鼻屎` | `/弹鼻屎 @某人` | 可选：@一名群友 | 对指定群友进行弹射；不指定目标时尝试随机选择一名群友。 |
| `/随机弹鼻屎` | `/随机弹鼻屎` | 无 | 随机抽取一名可用群友作为弹射目标。 |
| `/擦鼻屎` | `/擦鼻屎` | 无 | 清理自己脸上的鼻屎。 |
| `/帮擦` | `/帮擦 @某人` | 必须：@一名群友 | 尝试帮另一名群友清理鼻屎。 |
| `/鼻屎状态` | `/鼻屎状态` | 无 | 查看自己的鼻屎数量和恶臭值。 |
| `/鼻屎榜` | `/鼻屎榜` | 无 | 查看本群的鼻屎数量、恶臭值及弹射统计排行榜。 |
| `/今日鼻屎王` | `/今日鼻屎王` | 无 | 查看当天被命中次数最多的群友。 |
| `/整点播报 开` | `/整点播报 开` | 无 | 在当前群聊开启整点播报。 |
| `/整点播报 关` | `/整点播报 关` | 无 | 在当前群聊关闭整点播报。 |

### 指令补充说明

- 使用指定目标功能时，请通过平台的 @ 功能真正提及群友，而不是只输入昵称。
- `/弹鼻屎` 不带 @ 时，会尝试随机选择目标。
- `/帮擦` 必须指定其他群友，不能用于清理自己。
- `/整点播报 开` 和 `/整点播报 关` 只控制当前群聊；插件配置中的全局开关可以统一控制所有群的自动整点播报。
- 指令是否需要额外的命令前缀，取决于 AstrBot 的命令配置。

## 游戏规则

### 弹射结果

指定目标或随机目标的弹射结果按以下概率判定：

| 结果 | 概率 | 效果 |
| --- | ---: | --- |
| 命中 | 65% | 目标增加 1 颗鼻屎，并增加恶臭值。 |
| 闪避 | 20% | 目标躲开，不增加鼻屎。 |
| 反弹 | 10% | 鼻屎反弹到发射者自己脸上。 |
| 偏移 | 5% | 弹射偏离目标。 |

- 每名玩家最多累计 **100 颗鼻屎**。
- 恶臭值范围为 **0–100**。
- 每次增加鼻屎时，恶臭值随机增加 15–25，并且不会超过 100。
- 每位玩家每次弹射后有 **30 秒冷却时间**。
- 冷却时间按群聊和玩家分别计算。

### 擦鼻屎

使用 `/擦鼻屎` 清理自己脸上的鼻屎。

| 结果 | 概率 | 效果 |
| --- | ---: | --- |
| 清理成功 | 70% | 鼻屎数量减少 1，恶臭值减少 10。 |
| 擦空 | 20% | 清理失败，数值不变。 |
| 越擦越糟 | 10% | 鼻屎数量不变，恶臭值增加 10。 |

鼻屎数量和恶臭值最低为 0，最高为 100。若当前没有鼻屎，则会提示已经干净。

### 帮擦

使用 `/帮擦 @某人` 尝试帮其他群友清理。

| 结果 | 概率 | 效果 |
| --- | ---: | --- |
| 帮擦成功 | 70% | 对方减少 1 颗鼻屎，恶臭值减少 10。 |
| 转移事故 | 30% | 对方减少 1 颗鼻屎，帮助者自己增加 1 颗鼻屎，恶臭值增加 10。 |

- 只能在群聊中为其他群友帮擦。
- 不能通过该指令帮自己清理。
- 对方没有鼻屎时不会触发清理。

### 排行榜与每日鼻屎王

`/鼻屎榜` 展示两类排名：

1. **脸上最热闹**：按鼻屎数量和恶臭值排序。
2. **弹得最准**：按命中次数和出手次数排序。

`/今日鼻屎王` 用于查看当天被命中次数最多的群友。

## 自动播报

### 每小时整点播报

- 每小时整点尝试抽取一名群友并进行游戏结算。
- 整点播报可通过插件配置页面的全局开关统一开启或关闭。
- 也可以使用 `/整点播报 开`、`/整点播报 关` 分别控制当前群聊。
- 支持配置免打扰时段，默认 **00:00–08:00**。
- 免打扰期间跳过整点播报和每日播报。
- 整点抽中结果只播报昵称，不直接 @ 群友。
- 整点播报模式固定结算为命中，增加 1 颗鼻屎，并计入当日命中统计。
- 若平台适配器无法获取群成员列表，插件会尝试使用已有游戏记录；无法完成时可能跳过本次播报。

### 每日鼻屎王播报

- 插件尝试在每天 **23:00** 向有游戏记录的群聊发送每日播报。
- 根据当天被命中的次数评选鼻屎王。
- 若当天没有命中记录，则播报暂无鼻屎王。
- 定时任务使用运行 AstrBot 的本地系统时间。
- 自动播报需要 AstrBot 持续运行、插件保持启用，并且当前平台适配器支持群消息发送。

## 安装与使用

1. 下载插件 ZIP 安装包。
2. 在 AstrBot 中安装插件，并启用、加载插件。
3. 在群聊中发送 `/弹鼻屎游戏` 查看玩法菜单。
4. 使用上方表格中的指令开始游戏。

请确保安装包包含以下必要文件：

- `main.py`
- `metadata.yaml`
- `menu.png`

如果菜单图片缺失，插件可能无法正常显示图片版玩法菜单。

## 数据存储

游戏状态默认保存在：

`data/plugin_data/astrbot_plugin_booger/booger_state.json`

该文件包含各群的玩家状态、弹射统计、每日命中记录和冷却信息。

升级或替换插件时，建议提前备份游戏数据。不要在插件运行时手动编辑数据文件。

新版插件会尝试兼容迁移旧版数据；迁移后请检查游戏进度是否正常。

## 兼容性说明

- 插件基于 AstrBot 插件 API 编写，实际行为可能受到 AstrBot 版本和消息平台适配器影响。
- 获取群成员名单和真实昵称依赖平台适配器提供相应接口。
- 当群成员列表不可用时，随机抽选可能退回到已有游戏参与者。
- 自动播报依赖当前环境支持插件调用群消息发送接口。
- 不同平台对 @ 消息的处理方式可能存在差异。
