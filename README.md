# 群友弹鼻屎

一个用于 AstrBot 群聊的轻松整活小游戏。群友可以互相“弹鼻屎”、帮忙擦鼻屎、解锁成就称号、查看排行榜，并通过烤鼻屎制作群内料理，再由其他群友随机享用。所有数值均为虚构的游戏数据。

## 功能特色

- **图片版菜单与成就图鉴**：菜单、成就档案均使用图片展示，避免聊天客户端挤压长文本。
- **指定目标弹射**：可以 @ 一名群友进行弹射。
- **随机弹射**：从可获取的群成员名单或已记录的游戏参与者中抽取目标。
- **个人状态**：查看自己当前的鼻屎数量与恶臭值。
- **互相帮擦**：尝试帮其他群友清理，可能成功，也可能发生转移事故。
- **排行榜**：查看鼻屎数量、恶臭值及弹射命中统计。
- **成就称号**：鼻屎库存达到 10 至 10000 颗、连续被命中 5 次或恶臭值达到 100 时解锁称号。
- **鼻屎料理系统**：`/烤鼻屎` 消耗 1 颗原料随机制作普通、稀有、史诗或传说料理；`/鼻屎大餐` 查看本群待享用料理；`/吃鼻屎` 随机吃掉一道并触发效果。料理按群独立保存，记录制作人，其他人吃掉料理时主厨获得 20 点经验。
- **每日榜单**：查看今日神射手、今日背锅侠。
- **近七日榜单**：按近七天累计增加的恶臭值评选本周最臭。
- **每日鼻屎王**：根据当天被命中的次数评选，并在每天 23:00 播报，不受免打扰时段影响。
- **每日天选之子**：每天 00:00 从群成员中随机选出一人，当天免疫所有弹鼻屎攻击；播报不受免打扰时段影响。
- **每小时整点播报**：从平台获取本群全体成员名单，随机抽中一人并保证本次游戏结算为命中；可在插件配置页面通过“整点播报开关”全局开启或关闭；支持配置免打扰时段（默认 00:00（24点）–08:00），免打扰期间跳过整点随机弹射播报；每日天选之子和每日鼻屎王固定播报不受免打扰影响。整点抽中结果只播报昵称，不直接 @ 群友，也可用命令按群单独控制。
- **本地持久化**：游戏数据保存在 `data/plugin_data/astrbot_plugin_booger/booger_state.json` 中（升级时会兼容迁移旧版数据），重启后可继续使用。

## 游戏规则

### 弹射结果

指定目标或随机目标的弹射结果按以下概率判定：

- **65% 命中**：目标增加 1 颗鼻屎，并增加恶臭值。
- **20% 闪避**：目标躲开，不增加鼻屎。
- **10% 反弹**：鼻屎反弹到发射者自己脸上。
- **5% 偏移**：弹射偏离目标。

每名玩家最多累计 **100 颗鼻屎**，恶臭值最高为 **100**。每次增加鼻屎时，恶臭值会随机增加 15–25，并封顶 100。

每位玩家每次弹射后有 **30 秒冷却时间**。冷却按群聊和玩家分别计算。

### 擦鼻屎

使用 `/擦鼻屎` 清理自己脸上的鼻屎：

- **70% 清理成功**：鼻屎数量减少 1，恶臭值减少 10。
- **20% 擦空**：没有清理成功，数值不变。
- **10% 越擦越糟**：鼻屎数量不变，恶臭值增加 10。

数量和恶臭值最低为 0，最高为 100。若当前没有鼻屎，则会提示已经干净。

### 帮擦

使用 `/帮擦 @某人` 尝试帮对方清理：

- **70% 成功**：对方减少 1 颗鼻屎，恶臭值减少 10。
- **30% 转移事故**：对方减少 1 颗鼻屎，发起帮助的人自己增加 1 颗鼻屎，恶臭值增加 10。

只能在群聊中为其他群友帮擦，不能通过该指令帮自己清理。对方没有鼻屎时不会触发清理。

### 排行榜与每日鼻屎王

`/鼻屎榜` 展示两类排名：

1. **脸上最热闹**：按鼻屎数量和恶臭值排序。
2. **弹得最准**：按命中次数和出手次数排序。

`/今日鼻屎王` 会显示当天被命中次数最多的群友。

### 成就称号

| 称号 | 解锁条件 |
| --- | --- |
| 人体描边大师 | 连续被命中 5 次 |
| 生化武器 | 恶臭值达到 100 |
| 鼻屎收藏家 | 鼻屎数量达到 100 |

称号会保存在玩家资料中。使用 `/鼻屎状态` 可查看当前称号，使用 `/鼻屎成就` 查看成就列表。

### 新增榜单

- `/今日神射手`：按当天命中率排名，至少出手 3 次才参与，减少只出手一次就占榜的情况。
- `/今日背锅侠`：按当天帮擦转移事故次数排名。
- `/本周最臭`：统计当前日期及之前 6 天内累计增加的恶臭值，不会因玩家后来擦鼻屎而扣除历史记录。插件配置页面新增“整点播报开关”（默认开启），关闭后会停止所有群的自动整点播报；此外可用 `/整点播报 开` 或 `/整点播报 关` 按群单独控制。整点播报从平台提供的全体群成员名单中抽选，不受是否玩过游戏限制；该模式固定命中并增加 1 颗鼻屎，同时计入当日命中统计。若适配器无法获取群成员列表，则会记录警告并在群里说明本次未能完成。插件还会尝试在每天 **23:00** 向有游戏记录的群聊发送每日播报。自动播报能否发送，取决于当前 AstrBot 版本和消息平台适配器所提供的群消息发送接口。

## 安装与使用

1. 下载本项目的 ZIP 插件包，或将项目文件放入 AstrBot 的插件目录。
2. 在 AstrBot 中安装、启用并加载插件。
3. 在群聊中发送 `/弹鼻屎游戏` 查看玩法菜单。
4. 使用上方指令开始游戏。

请确保安装包中包含 `main.py`、`metadata.yaml` 和 `menu.png`。如果菜单图片缺失，插件会提示重新安装完整插件包。

## 数据存储

游戏状态默认保存在插件目录下：

```text
data/plugin_data/astrbot_plugin_booger/booger_state.json
```

文件包含各群的玩家状态、弹射统计、每日命中记录和冷却信息。卸载或替换插件时，如需保留游戏进度，请备份该文件；不要在插件运行时手动编辑它。

## 兼容性说明

- 插件基于 AstrBot 插件 API 编写，具体行为会受到 AstrBot 版本和消息平台适配器影响。
- 获取群成员名单和真实昵称依赖平台适配器提供相应接口；接口不可用时，随机抽选会尝试使用已有游戏记录，昵称也可能退回到 ID 简写。
- 每日自动播报需要当前环境支持插件调用群消息发送接口。

## 自动播报

- **每小时整点**：插件从本群已记录的参与者中随机抽取一人，按游戏概率结算，并在群内播报命中、闪避、反弹或偏移结果。
- **每天 00:00**：选出今日天选之子，全天免疫弹鼻屎攻击；此播报不受免打扰时段影响。
- **每天 23:00**：公布当天被命中次数最多的群友；若当天没有命中记录，则播报暂无鼻屎王；此播报不受免打扰时段影响。
- 定时任务使用运行 AstrBot 的本地系统时间。需要 AstrBot 持续运行，且插件保持启用。若群内尚无已记录的参与者，整点弹射会跳过。
